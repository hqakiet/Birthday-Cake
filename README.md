# Birthday-Cake

Ứng dụng bánh sinh nhật chạy bằng React, TypeScript và Vite.

## Chạy local

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deploy GitHub Pages

Repository đã được cấu hình GitHub Actions. Sau khi push lên nhánh `main`, mở **Settings > Pages**, chọn **Source: GitHub Actions**.
